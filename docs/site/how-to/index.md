# How-to guides

Task recipes. Each assumes sibling checkouts of this repo and of the platform
repos it patches.

## Consume the kernel

Depend on `handl-lang/kernel` at branch `main`; for local development the consumer's `[patch]` table points at `../kernel` (regenerated by `host/scripts/dev-link.sh`).

## Add a language fragment

Extend the `Language` schema in `handl-language`, then teach the engines — the schema is the contract, so an engine change is expected to follow a schema change, not the other way round.
