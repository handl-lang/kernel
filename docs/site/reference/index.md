# Reference

## Public API

| item | what it is |
|---|---|
| `handl_language::Language` | the language value: tokens, grammar, eval schemes, globals, capabilities |
| `handl_language::Ast` / `AstRef` | the arena and its handle |
| `handl_value::Value` / `TaggedValue` | the tagged value representation |
| `hnl_engine::LanguageView` | the object-safe view engines use (`handl-language` implements it) |
| `handl_lib_*` packages | the floor libraries every host gets for free |

## Crate

| crate | role |
|---|---|
| `handl-lang/kernel` | substrate workspace |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # cargo test --workspace
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
